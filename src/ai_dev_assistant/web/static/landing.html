How it works

01

Plan

The orchestrator decomposes your prompt into subtasks with dependencies, routed to specialist agents — reviewable and steerable before anything runs.

02

Execute in parallel

Independent subtasks run concurrently, each in its own git worktree with per-subtask commits. Live transcripts show every thought, tool call, and result.

03

Objective review

A reviewer scores each subtask against acceptance criteria and baseline-delta tests. Failures self-heal with bounded repair attempts.

04

Deliver

Accepted work lands on an ada/* branch — cherry-pick per subtask or take the whole task. Your repo is never touched without you.

Features

Project-first

Create greenfield projects or import an existing repo in place under a strict read-only contract — the assistant only ever writes to its own branches.

Attention screens

Agents can ask you questions and request permission mid-run; asks and grants are first-class screens in the console.

Self-healing runs

Review-failed, errored, and timed-out subtasks get bounded automatic repair subtasks — retries are visible, never silent.

Live transcripts

Full per-subtask agent conversations — thinking, tool calls, tool results — streamed live and browsable for every past run.

Sandboxed execution

Agent shell commands run under rlimits, bwrap, or a container — configurable from the settings console. The model loop stays on your login.

Cost analytics

Per-run and per-subtask spend, budgets that stop work mid-subtask, cost-per-outcome across projects.

Playbooks & schedules

One-click pre-tuned task templates, plus recurring runs on a timer with their own budgets.

Memory & knowledge

Project memory, a knowledge graph built from every run, drag-and-drop knowledge base, and global search under ⌘K.

Quick start

Local (recommended)

Requires uv and a logged-in Claude Code — the SDK reuses your login, no API key.

git clone https://github.com/Mayank-240/dev-assistant
cd dev-assistant
uv run ai-dev-assistant server
# console at http://localhost:8000/app

Docker (one line)

Published to GHCR on every commit. The container can't reach your host login, so it takes an API key instead.

docker run -d --name ada -p 8000:8000 -v ada-data:/data \
  -e ANTHROPIC_API_KEY=sk-ant-... \
  ghcr.io/mayank-240/dev-assistant:latest
